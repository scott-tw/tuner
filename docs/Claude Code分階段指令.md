# 給 Claude Code 的分階段指令

每一段複製貼上給 Claude Code。等上一階段完成、您實測沒問題後，再貼下一段。

---

## 階段 1：偵測引擎

請先完整閱讀 CLAUDE.md 和 SPEC.md，然後先用計畫模式告訴我你打算怎麼做，等我同意再開始寫程式。

這一步只做 SPEC.md 第 11 節的「階段 1」：完成 js/pitch.js 的 YIN 偵測引擎，以及 tests/pitch.test.js 的自動測試。請特別測試弱基頻的男聲合成音，確認八度判斷正確。完成後告訴我測試結果（每種情況的誤差與八度正確率）。

---

## 階段 2：樂器調音器

請做 SPEC.md 的「階段 2」：首頁兩個大按鈕、設定頁（A4 基準音、音名顯示方式）、樂器調音畫面、麥克風權限處理、「點一下繼續」、螢幕保持亮著。

另外請做 tools/test-tone.html，讓我可以用另一台裝置播放指定頻率來測試。

完成後推送到 GitHub，並告訴我手機要開哪個網址測試。

---

## 階段 3：人聲模式

請做 SPEC.md 的「階段 3」：聲音類型（童聲／女聲／男聲）、三層八度防護、大字音名與五線譜顯示。

完成後告訴我建議怎麼測試男聲、女聲、童聲的八度是否正確。

---

## 階段 4：軌跡圖與參考音

請做 SPEC.md 的「階段 4」：音高軌跡圖（最近 10 秒）、目標音選擇、參考音播放（含持續長音）、童聲模式的變聲提示。

---

## 階段 5：PWA 與正式部署

請做 SPEC.md 的「階段 5」：manifest、Service Worker、App 圖示，確認 Android 可以「安裝應用程式」、飛航模式下可以開啟。最後更新 README，寫一份給合唱團團員看的簡短安裝說明。

---

## 實測後回報問題的寫法（範例）

> 在 Galaxy Tab 人聲模式選男聲，唱 A2 時畫面有時跳成 A3，大約每 3 秒跳一次。請檢查八度防護的連續性判斷，修正後重新執行測試。

描述越具體（哪台裝置、哪個模式、唱或彈什麼音、發生頻率），Claude Code 越容易修正。
